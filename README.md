# Café Pomodoro ☕

一杯咖啡的时间，一次思考的拓片。

一个复古风格的专注计时器：用一杯逐渐减少的咖啡来可视化时间，杯壁上停留的圈痕则成为你思考节奏的「拓片」。

## 两种模式

- **倒计时（一杯咖啡的时间）**：选一杯咖啡（对应不同时长），咖啡随时间一口口减少，喝完即专注结束。无数字、去焦虑。
- **正计时（跟随专注 · 需摄像头）**：摄像头在本地判断你是否专注——目光落在工作上时咖啡几乎不动；目光离开工作即「啜一口」，液面下降并留下一道圈痕。圈痕深浅 ∝ 这段心流的时长。

> 摄像头画面与所有推理**全部在本机浏览器内完成，不录制、不上传**。

## 圈痕语义

- **圈痕 = 一段心流**，深浅编码这段心流的时长。
- **空隙 = 一次走神/啜饮**，间距编码这次抽离的长短。
- 杯子不是成绩单，是你今天思考节奏的一张拓片。

## 技术

- React 19 + TypeScript + Vite + Tailwind CSS v4
- 注意力判定基于 [MediaPipe Tasks Vision](https://developers.google.com/mediapipe)（FaceLandmarker），合成「视线方向 + 头部俯仰」信号，进场快速校准 + 非对称迟滞去抖。

## 本地运行

```bash
npm install
npm run dev      # 默认 http://localhost:3000
npm run build    # 产物输出到 dist/
```

## 开发工具

`/probe.html` 是注意力探针——实时显示各信号与阈值滑块，用于在真实环境下标定判定参数。
